# Netflix Landing Page Clone

## Description
This project is a clone of the Netflix landing page, designed to provide a similar look and feel as the original site. The project showcases how to utilize modern web development practices and technologies to create a functional user interface that mimics the original Netflix website.

## Features
- Responsive design that works on both mobile and desktop browsers.
- Interactive components, including navigation, video backgrounds, and user login prompts.
- Implementation of animations and transitions to enhance user experience.

## Installation
To install the project locally, follow these steps:
1. Clone the repository:
   ```
   git clone https://github.com/dhanu1999/Netflix-landing-page.git
   ```
2. Navigate to the project directory:
   ```
   cd Netflix-landing-page
   ```
3. Open the `index.html` file in your web browser.

## Usage
- Open the `index.html` file in a web browser to view the landing page.
- Explore the interactive elements and layout.
